# 🖼️ WallpaperNamer

Renames wallpaper images using titles generated by a vision model served through LM Studio. Scans subfolders and skips filenames that already start with an uppercase letter.

## 🔧 Setup

1. Install [Python 3.9+](https://www.python.org/downloads/) and [LM Studio](https://lmstudio.ai/), then download and load a vision-capable model.
2. Install the Python dependencies:
   ```sh
   python -m pip install -r requirements.txt
   ```
   Pillow is used to convert WebP images to PNG before sending them to the model.
3. Edit the settings at the top of `src/wallpaper_namer.py`:
   - `IMAGE_DIR`: folder containing your wallpapers (default: `E:\Images\Wallpapers`).
   - `MODEL_NAME`: your model's ID (default: `qwen3vl-8b-thinking`).
   - `API_URL`: chat completions endpoint (default: `http://localhost:1234/v1/chat/completions`).
4. Start LM Studio's local server. If it is not running, the script tries to start it using `lms` on your PATH. Set `LMS_LOAD_MODEL` if you want the script to load a model automatically.

## ▶️ Usage

From the project directory, run:

```sh
python src/wallpaper_namer.py
```

**Back up your images first.** Files are renamed in place, without a preview or confirmation. Supported extensions: JPG, JPEG, PNG, GIF, BMP, WebP, and TIFF; model support may vary.

Edit `src/prompt.md` to change the naming instructions. The script uses the returned title as the filename, removes invalid filename characters, and checks for duplicate names.

## 🧪 Tests

Run from the project directory (no LM Studio server needed):

```sh
python -m unittest discover -s tests
```
